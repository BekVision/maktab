#04 O'zgaruvchilar
a = 10, b = 3 o'zgaruvchilarini e'lon qiling va ularning darajasini (a ** b) chiqaring.
Ikkita o'zgaruvchi qiymatini uchinchi o'zgaruvchi yordamida almashtiring, so'ng uni Python usulida (a, b = b, a) qayta yozing.
Foydalanuvchi ismi, yoshi va bo'yini o'zgaruvchilarga yozib, type() orqali har birining turini chiqaring.
Tovar narxi 250000 so'm. 15% chegirmadan keyingi narxni o'zgaruvchilar orqali hisoblang.
Xatoni toping: qaysilari to'g'ri o'zgaruvchi nomi? 2son, son_2, my-var, _narx, class, Narx.
